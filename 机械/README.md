# Mechanical models and drawings / 机械模型与工程图

[Repository guide / 仓库说明](../README.md) · [Drawing index / 工程图索引](%E5%B7%A5%E7%A8%8B%E5%9B%BE/) · [Original project index / 原项目索引](../docs/PROJECT_FILES.md)

The 16 original SolidWorks assembly/part files in this directory were restored unchanged from the original uploaded commit. The new `工程图/` subdirectory contains the author's engineering drawings corresponding to the thesis, as original PDF, PNG and SolidWorks files, together with the original thesis images and a hash manifest.

本目录的16个原SolidWorks装配体、零件文件已从原上传提交原样恢复。新增`工程图/`子目录保留论文终稿对应的原PDF、PNG、SolidWorks工程图，以及论文原图和文件校验清单。

## Drawings / 工程图

[Open the five drawing groups and thesis-figure mapping / 查看五组工程图及论文原图对应关系](%E5%B7%A5%E7%A8%8B%E5%9B%BE/)。PDF可独立查看尺寸；PNG用于快速浏览；SolidWorks原件用于后续编辑。
