该程序为野火STM32F103C8T6-STM32开发板所做的VL53L0X激光测距传感器实验，用于钻具机构设计
/*【*】程序简介

- 工程名称        ：VL53L0X 激光测距传感器实验
- 实验平台        ：野火 STM32F103C8T6-STM32开发板  

【 ！】功能简介：

本实验实现 VL53L0X 激光测距模块的初始化、周期性读取并通过串口打印测量距离值（单位：mm）

【 ！】实验操作：

    1. 编译并下载程序到开发板；
    2. 打开串口调试助手，观察 0.5s 周期输出的测距数据；
    3. 对传感器前方不同距离放置障碍物，可观察数据变化；
*/
/*********************************************************************************************/

/*【*】 引脚分配

NRST -> NRST              按键按下为低电平，核心板板载默认上拉且硬件有消抖

DEBUG_TX -> USART1_TXD -> PA9     PA9 作为 USART1 的 TXD，用于串口打印调试信息  
DEBUG_RX -> USART1_RXD -> PA10    PA10 作为 USART1 的 RXD，默认接收不使用

IIC_SCL -> PB10            PB10 作为硬件 I2C 的 SCL，引脚连接 VL53L0X 的 SCL
IIC_SDA -> PB11            PB11 作为硬件 I2C 的 SDA，引脚连接 VL53L0X 的 SDA

XSHUT  -> PB8             VL53L0X 的硬件复位引脚，用于模块地址配置或重新上电（可选连接）
INT    -> PB9             VL53L0X 的中断引脚（可选连接），用于新数据到达中断

*/
/*********************************************************************************************/

/*【*】程序描述：

< main.c >

    1. 初始化 USART1，用于打印测距数据；
    2. 初始化 I2C2，并配置 VL53L0X 相关寄存器；
    3. 使用 VL53L0X 驱动库完成传感器初始化与数据获取；
    4. 主循环中每隔 0.5 秒读取一次距离并打印到串口；
    5. 可扩展多个 VL53L0X 模块进行多点测距（需使用 XSHUT 引脚设置不同 I2C 地址）；
*/
/*********************************************************************************************/
